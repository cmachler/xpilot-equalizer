xPilot Audio Normalizer

Live VATSIM voice normalization for xPilot. Presets, parameters, .eq commands, settings UI, and live level meters. DSP runs on the live headset/speaker audio path.

Download latest MSI Source code Architecture

Per-user install, no elevation. Close xPilot before installing or uninstalling.

Install

  1. Download XpilotAudioEqualizer.msi from the latest release.
  2. Run msiexec /i XpilotAudioEqualizer.msi /qn or use the installer wizard.
  3. Restart xPilot. The debug log should show xPilot Audio Normalizer 1.0.0 loaded ... Type .eq to open settings.

Files land in %LOCALAPPDATA%\org.vatsim.xpilot\Plugins\XpilotAudioEqualizer\.

Commands

CommandEffect
.eq / .eq show / .eq guiOpen settings window
.eq hide / .eq closeHide settings window
.eq on / .eq off / .eq toggleArm / disarm normalization
.eq target <-30..-6>Set target loudness in dBFS
.eq preset <balanced|aggressive|gentle|night>Apply preset
.eq statusShow armed state, preset, target, boost/cut, ratio
.eq resetReset to Balanced defaults

Any slider move or .eq target switches the preset label to Custom.

Uninstall

Use Add/Remove Programs, or run:

msiexec /x dist\XpilotAudioEqualizer.msi /qn

A runtime-created normalizer-config.json may remain; delete it manually if desired.
